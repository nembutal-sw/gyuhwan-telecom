# 관리자 계정과 수정 기록

**관리자 계정**에서 자신의 아이디와 비밀번호를 변경합니다. 아이디는 영문·숫자·점·밑줄·하이픈 3~50자이고 대소문자를 구분하지 않고 로그인합니다. 비밀번호는 16~128자로 입력합니다. 현재 비밀번호를 확인해야 저장할 수 있습니다.

**내 계정 수정**에서 로그인 아이디와 현재 비밀번호를 입력합니다. 비밀번호도 바꾸려면 같은 줄의 새 비밀번호·확인 칸을 모두 입력하고, 바꾸지 않으려면 두 칸을 비워 둡니다. **변경 전 확인**으로 수정 내용을 검토한 뒤 **계정 정보 저장**을 누릅니다. **계정 식별 정보**는 계정을 구분하는 내부 ID를 확인할 때만 펼칩니다.

최초 대표 관리자만 다른 관리자를 추가하거나 다른 계정의 아이디·비밀번호를 변경합니다. 다른 계정 변경에도 대표 관리자의 현재 비밀번호를 확인합니다. 일반 관리자는 자신의 계정 변경과 가격·메인 관리·수정 기록 조회를 사용할 수 있습니다. 계정 삭제·권한 변경은 제공하지 않습니다.

자신의 아이디나 비밀번호를 바꾸면 다시 로그인합니다. 다른 관리자의 계정을 바꾸면 그 계정이 로그인했던 모든 서버의 기존 JWT가 무효화됩니다. 동일한 값을 저장하면 새 수정 기록을 만들지 않습니다. 다른 화면에서 계정 정보를 먼저 바꿨으면 최신 정보를 다시 확인한 뒤 수정합니다.

## 수정 기록

**수정 기록**에서 관리자 아이디·작업·대상을 검색하고 최신 기록 50개씩 확인합니다. 시각은 한국 시간입니다. 각 기록의 **무엇이 바뀌었나요? · 변경 전후 확인**을 펼치면 수정한 항목과 수정 전·후 값을 나란히 볼 수 있습니다. 금액에는 쉼표와 원 단위를 표시하며, 목록·객체는 항목별로 표시하고 안내 문구의 줄바꿈을 유지합니다. **항목 코드**와 **기록 식별 정보**는 내부 코드를 확인할 때만 펼칩니다.

기록 대상: 가격표·구매 조건 수정, 엑셀 가격표 적용, 가격표의 이전 저장본 적용, 메인 구역 저장, 메인페이지의 이전 저장본 적용, 사진 업로드, 관리자 추가·변경입니다. 기존 기능이 없던 시기의 이력에는 수행한 관리자를 알 수 없어 새 변경 기록으로 소급 작성하지 않습니다.

가격·내용·계정 변경과 기록은 같은 DB 트랜잭션으로 저장하므로 기록 저장에 실패하면 변경도 취소됩니다. 사진 업로드 기록에 실패하면 새 사진 파일을 제거합니다. 비밀번호는 '설정됨/변경됨' 상태만 기록하고 실제 비밀번호·해시는 포함하지 않습니다. 색상 사진 데이터는 크기와 해시 일부로 요약합니다.

사진을 올리면 파일과 업로드 기록이 먼저 저장됩니다. 해당 사진을 실제 메인 페이지에 적용하려면 **변경 내용 저장 → 고객 페이지에 저장**까지 완료해야 합니다. 기록 조회는 가능하며 관리자 화면에 기록 수정·삭제 기능은 없습니다.
