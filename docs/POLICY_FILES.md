# 가격표 셀 편집과 엑셀 관리

**가격표 관리**에서 48개 용량별 모델의 가격·요금제·안내 문구·색상별 사진을 관리합니다. 표에는 모델 × 통신사 × 가입 유형 × 할인 방식으로 구분한 864개 조건이 있으며, 미등록 조건도 표시합니다.

처음 열면 **SKT · 번호이동 · 공통·유통망 지원금** 조건의 **48개 모델을 모두** 보여줍니다. 모델을 따로 선택할 필요 없이 아래로 스크롤하면서 각 모델의 셀을 바로 수정합니다. 제조사는 전체, 검색어는 빈칸으로 시작합니다. 다른 통신사나 가입 조건은 위 필터에서 선택합니다.

## 화면에서 셀 편집

1. **통신사**, **제조사**, **가입 유형**, **할인 방식**을 선택하거나 **직접 검색**에 모델명·용량·모델 코드·요금제명을 입력합니다. 제조사의 `Apple`은 화면에 **애플**로 표시합니다. **수정한 행만 보기**로 변경한 조건을 모을 수 있습니다.
2. **금액·요금제** 또는 **안내 문구** 탭에서 셀을 클릭해 수정합니다. 입력한 변경은 파란색으로 표시됩니다. 필터·검색·탭·페이지를 바꿔도 입력값이 유지됩니다.
3. 상단의 전체 변경 조건·항목 수를 확인합니다. **변경 내용 저장**을 누르면 현재 필터에 보이지 않는 행까지 변경 전후를 한 창에서 비교합니다.
4. **가격표 전체 변경 저장**을 누르면 여러 모델과 조건의 변경을 한 번에 저장합니다. 더 수정하려면 **계속 수정**을 누릅니다.

**표시할 행**의 기본값은 **전체 보기**입니다. 필터에 맞는 모든 행을 표시하며, 필요하면 **25개씩·50개씩·100개씩**으로 나누어 볼 수 있습니다. 표를 가로로 이동하면 나머지 열을 볼 수 있습니다. **Tab**은 다음 칸, **Enter·↑↓**는 같은 열의 다른 행으로 이동합니다. 안내 문구 칸에서는 Enter로 줄을 바꾸고 Ctrl+↑↓로 행을 이동합니다.

| 탭 | 수정 내용 |
| --- | --- |
| 금액·요금제 | 출고가, 공통·유통망 지원금, 추가지원금, 요금제명, 월정액, 선택약정 기준액, 월 부가요금, 청구 개월, 문의 표시 |
| 안내 문구 | 요금제명, 요금제·유지 조건, 부가서비스, 위약금, 구매 조건·유의사항 |
| 색상·사진 | 선택한 모델의 색상 목록과 색상별 사진 |

금액은 원 단위 정수입니다. **0은 실제 0원**, **빈칸은 미등록**입니다. 선택약정의 공통 지원금처럼 적용되지 않는 칸은 비활성화됩니다. 할부이자와 첫 달 월 납부액은 계산 결과로 표시되며 직접 입력하지 않습니다. 오류가 있으면 해당 행·셀을 표시하고 **오류 행 확인**으로 확인할 수 있습니다.

### 엑셀에서 여러 셀 붙여넣기

엑셀에서 복사한 셀 범위를 표의 시작 칸에 붙여넣을 수 있습니다. **현재 탭의 편집 열 순서와 현재 페이지에 보이는 행**에 맞춰 복사하세요. 모델·조건 표시 열, 문의 체크 항목, 계산 결과 열은 붙여넣기 범위에 포함되지 않습니다.

붙여넣을 범위가 현재 페이지의 남은 행이나 편집 열을 넘으면 적용하지 않습니다. 페이지당 행 수를 늘리거나 범위를 나눠 붙여넣습니다. 비활성화된 칸에는 빈칸을 넣어야 합니다. 금액 칸에는 수식 대신 정수 값을 사용합니다. 붙여넣기도 저장 전 입력이며 마지막에 전체 변경을 검토·저장해야 반영됩니다.

### 부가서비스·색상·견적

기존 24개월 월별 부가요금 내역은 다른 가격·문구를 수정할 때 유지됩니다. **월 부가요금**이나 **청구 개월**이 바뀌면 기존 월별 내역을 해제하고 새 요금·기간으로 계산합니다. 출고가·지원금 등 원금 관련 금액이 바뀌면 연 5.9%·24개월 기준 할부이자를 자동 계산합니다. 음수 추가지원금이나 문의 표시를 사용하면 지원금 계산값을 0원으로 저장합니다.

**색상·사진** 탭에서 모델을 선택합니다. 색상은 쉼표로 구분하고, 비우면 기본 색상을 사용합니다. PNG·JPG·WebP 사진을 선택하거나 **기본 색상 표시**로 되돌릴 수 있습니다. 색상·사진은 그 모델의 모든 통신사·가입 조건에 공통 적용됩니다. 모델을 바꿔도 입력을 유지하며 가격·문구 변경과 함께 상단에서 저장합니다.

행 오른쪽 **상세**에서 견적과 기존 월별 부가요금을 확인합니다. **메인페이지에서 미리보기**는 선택한 조건의 수정 중인 견적을 고객 페이지 형태로 보여줍니다. **이 모델 색상·사진 수정**으로 해당 모델의 사진 편집에 이동할 수 있습니다.

## 엑셀 파일 다운로드·업로드

1. **엑셀 다운로드·업로드**를 펼친 뒤 **전체 모델 엑셀 다운로드**로 현재 저장된 `.xlsx`를 받습니다.
2. **가격 정책** 시트의 금액·요금제·안내 문구를 수정합니다.
3. 수정한 파일을 선택해 변경 전후 값과 변경 조건 수를 확인합니다.
4. **가격 정책 적용**을 누르면 검증한 변경을 한 번에 저장합니다.

다운로드에는 서버에 저장된 값이 들어갑니다. 화면에서 입력 중인 값은 먼저 저장하거나 취소한 뒤 엑셀 파일을 사용하세요. 파일은 1.5MB 이하 `.xlsx`만 지원합니다. 수식이 있는 셀은 **값 붙여넣기**로 바꿉니다. 잘못된 셀이나 중복 조건이 있으면 파일 전체를 적용하지 않습니다.

가져올 파일을 검토할 때는 **현재 적용된 가격표의 마지막 저장 시각**이 함께 표시됩니다. 이 저장본과 엑셀의 변경 전후를 비교한 뒤 적용하세요.

## 시트와 수정 범위

- **가격 정책**: 48개 용량별 모델 × 3개 통신사 × 3개 가입 유형 × 2개 할인 방식 = 864개 조건. 미등록 조건도 표시합니다.
- **모델 목록**: 모델 기본 정보·색상·사진 경로를 확인하는 참고 시트입니다. 이 시트를 수정해도 모델 정보나 사진을 변경하지 않습니다. 대표 사진·모델 문구는 **메인 페이지 관리**, 색상별 사진은 가격표의 **색상·사진** 탭에서 수정합니다.

첫째 행은 다운로드 기준 버전·시각, 셋째 행은 열 제목, 넷째 행부터 데이터입니다. 제목을 유지해 주세요. 행 순서를 바꾸거나 일부 행만 남겨도 조건 키를 기준으로 반영합니다.

| 열 | 용도 |
|---|---|
| A · 모델 ID | 조건 식별, 변경하지 않음 |
| B~E · 모델 정보 | 참고 표시 |
| F · 통신사 | `SKT`, `KT`, `LG U+` |
| G · 가입 유형 | `번호이동`, `기기변경`, `신규가입` |
| H · 할인 키 | `common`, `choice` |
| I · 상태 | `등록`, `미등록` |
| J~X · 정책 | 금액·요금제·안내 문구·문의 표시·월별 부가서비스 요금 |

금액은 원 단위 정수입니다. **0은 실제 0원**, **빈칸은 미등록**입니다. 기존 조건의 금액을 지우면 미등록으로 바뀌고 문구를 지우면 문구를 비웁니다. 미등록 조건의 정책 칸이 모두 비어 있으면 새 조건을 만들지 않습니다. 다운로드한 파일을 그대로 올리면 새 저장본이나 수정 기록을 만들지 않습니다.

음수 추가지원금은 문의 표시·계산값 0원으로 정리합니다. 원금 관련 금액이 바뀌면 연 5.9%·24개월 기준 할부이자를 자동 계산합니다. 월별 부가서비스 요금은 24개 정수 배열이고, 빈칸이면 별도 월별 내역을 제거합니다. 가격 업로드는 기존 색상과 색상별 사진을 유지합니다.

미리보기 이후 다른 화면에서 저장하면 최신 설정을 불러와 파일을 다시 선택합니다.

## 현재 적용된 데이터 확인

화면 상단에는 **고객페이지에 적용된 저장본**, **마지막 저장**, **이 화면에서 확인한 시각**이 표시됩니다. **마지막 저장**은 이 서버의 가격표를 마지막으로 저장한 시각이고, **이 화면에서 확인한 시각**은 관리자 화면이 그 데이터를 가져온 시각입니다. 가격표의 별도 적용일이나 통신사 공지일을 뜻하지 않습니다. 수정 중에는 **저장하지 않은 변경이 있습니다**로 표시합니다.

하단 **현재 적용 중인 가격표**에서 어떤 데이터를 확인하는지 다시 볼 수 있습니다. **현재 적용 중인 가격표 다시 확인**을 누르면 대상과 마지막 저장 시각을 확인하는 창이 열립니다. **현재 가격표 가져오기**를 누르면 고객 메인페이지에 현재 적용된 전체 모델 가격·요금제·구매 조건을 서버에서 다시 가져옵니다. 다른 관리자가 그 뒤 저장했으면 더 최신 저장본을 가져옵니다. 저장하지 않은 입력은 취소되므로, 입력을 남기려면 **계속 수정**을 누릅니다.

## 저장 충돌·입력 취소·이전 저장본

다른 관리자나 다른 창이 먼저 저장하면 현재 입력을 유지하며 충돌을 알립니다. **최신 가격 불러오기 · 입력 유지** 후 최신 값과 변경 전후를 다시 확인합니다. **변경 취소**는 표와 색상·사진에서 아직 저장하지 않은 모든 입력을 취소합니다.

하단 **이전 저장본으로 되돌리기**를 펼치면 저장 시각별로 이전 내용을 선택할 수 있습니다. 원하는 날짜·시각의 **이 저장본으로 되돌리기**를 누르고 확인창에서 **이 저장본 적용하기**를 누릅니다. 현재 필터와 관계없이 가격·구매 조건·색상·사진 설정 전체를 해당 저장본으로 바꾸며, 저장하지 않은 입력도 취소합니다. 고객페이지에도 바로 반영됩니다.
