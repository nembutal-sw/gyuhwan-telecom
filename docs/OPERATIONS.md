# 매장 운영 안내

관리자 로그인 주소는 `/admin_login`, 관리 화면은 `/admin`, 고객 페이지는 `/`입니다. 관리자마다 허용된 업무가 달라 수정 버튼이나 통계 메뉴가 보이지 않을 수 있습니다.

## 화면에서 수정한 내용이 공개되는 시점

| 작업 | 고객에게 반영되는 시점 |
| --- | --- |
| 가격표 셀·구매 조건·색상 사진 수정 | 변경 전후를 확인하고 **고객페이지에 공개**를 확정했을 때 |
| 메인 페이지 문구·사진·링크·영상 수정 | 변경 전후를 확인하고 **고객페이지에 공개**를 확정했을 때 |
| 내 임시 작업 저장·이어하기 | 고객 페이지에 공개되지 않음 |
| 가격표 예약 등록 | 예약 시작 시 서버가 적용 조건을 확인하고 공개했을 때 |
| 모델 등록·모델/색상 판매 상태·숨김 | 저장 전 확인 후 **확인하고 저장**을 눌렀을 때 |
| 사진 보관함 업로드·이름 변경 | 파일은 보관함에 저장됨. 페이지나 가격표에서 선택하고 공개해야 화면에 사용됨 |

가격표와 메인 페이지의 공개본, 내 계정의 임시 작업, 이전 공개 저장본은 별도로 관리됩니다. `마지막 저장`은 공개본의 시각이고, `마지막 임시 저장`은 내 작성 중인 작업의 시각입니다.

## 1. 자동 임시 저장과 작업 이어가기

가격표와 메인 페이지에서 입력을 잠시 멈추면 서버에 내 작업이 임시 저장됩니다. 창을 닫거나 로그아웃하기 전 **서버에 임시 저장됨** 표시와 시각을 확인하세요. 바로 저장하려면 **지금 임시 저장**을 누릅니다.

다시 로그인하면 이전 작업이 있는 화면에 **저장된 작업 이어하기**와 **임시 작업 삭제**가 표시됩니다. 이어하기는 내 입력을 편집 화면으로 가져오고, 삭제는 공개본부터 다시 시작합니다. 다른 직원의 임시 작업은 보이지 않습니다.

공개본이 작업 시작 당시와 달라졌다는 안내가 나오면 **최신 가격 불러오기 · 입력 유지** 또는 **최신 내용 불러오기 · 입력 유지**를 사용합니다. 입력값은 유지되므로 현재 공개본과 변경 전후를 다시 확인하고 공개하세요.

같은 계정으로 두 창에서 작업해 임시 저장이 충돌하면 서버 작업을 다시 확인해야 합니다. 자동으로 한 창의 입력을 다른 창 위에 덮어쓰지 않습니다. 계정 아이디·비밀번호를 변경하기 전에도 임시 저장 완료를 확인하세요.

모델 등록과 계정 수정 폼은 이 자동 임시 저장 대상에 포함되지 않습니다. 해당 화면의 저장 확인을 마친 뒤 이동하세요.

## 2. 선택한 가격표 일괄 수정

1. **가격·구매 조건**에서 통신사·제조사·가입 조건·검색어로 원하는 행을 찾습니다.
2. 행 왼쪽 체크박스로 수정할 가격 조건을 선택합니다.
3. 일괄 수정에서 **같은 값 지정**, **현재 금액에 증감**, **요금제·유지 조건 복사** 중 하나를 고릅니다.
4. **변경 전후 확인**으로 대상 수와 바뀔 값을 확인하고 **내 편집본에 반영**합니다.
5. 상단의 **고객페이지에 공개**에서 전체 변경을 확인하고 확정합니다.

선택은 필터를 바꿔도 유지됩니다. 현재 화면에서 보이지 않는 선택 행도 적용 대상이므로 선택 개수를 확인하세요. 선택약정에는 공통 지원금을 넣을 수 없는 것처럼, 할인 방식에 적용되지 않는 항목은 제외되거나 오류로 안내됩니다.

증감은 기존 금액이 등록된 행에 사용할 수 있습니다. 미등록 금액은 먼저 같은 값 지정으로 입력하세요. 요금제·유지 조건 복사는 대상 모델의 출고가와 지원금을 유지합니다. 빈 금액은 **미등록**이며 0원과 의미가 다릅니다.

엑셀로 확인하려면 현재 공개된 전체 가격표를 내려받습니다. 엑셀을 다시 올릴 때에도 변경 전후를 확인한 뒤 적용합니다. 신규 모델은 모델 관리에서 먼저 등록하고 최신 엑셀을 다시 내려받아 작업하세요.

## 3. 가격 정책 적용 기간과 예약

가격표 아래 **가격표 적용 기간·예약 관리**를 펼칩니다. 편집 중인 가격표 또는 현재 공개 가격표를 예약할 수 있습니다.

예약 이름과 시작·종료 시각을 입력하고 예약 검토 후 확정합니다. 모든 입력·표시 시각은 **한국 시간**입니다. 종료 시각을 비우면 시작 이후 계속 적용합니다. 예약은 특정 행만 적용하는 기능이 아니라 예약할 때 확인한 **전체 가격표**를 적용합니다.

종료 시에는 **예약을 만든 시점에 고객페이지에 공개되어 있던 전체 가격표**로 복귀합니다. 시작 시 공개본이 예약의 기준 내용과 달라졌거나, 적용 중 수동 저장으로 공개본이 변경되면 자동 적용·복귀를 중지하고 **운영자 확인 필요**로 표시합니다. 현재 공개 가격표를 확인하고 필요한 내용을 새로 공개하거나 예약하세요.

| 예약 상태 | 운영자가 확인할 내용 |
| --- | --- |
| 적용 예정 | 시작·종료 시각과 예약한 전체 가격표 |
| 적용 중 | 고객페이지에서 실제 적용 중인 가격과 종료 시각 |
| 기간 종료 | 예약 당시 가격표로 복귀한 결과 |
| 운영자 확인 필요 | 안내 열의 중지 사유와 현재 공개 가격표 |
| 기간 지나 적용 안 함 | 서버가 처리할 시점에 기간이 이미 끝나 공개하지 않은 예약 |
| 취소됨 | 시작 전 취소 또는 적용 중 종료한 예약 |

다른 예약과 적용 기간이 겹치면 등록할 수 없습니다. 적용 중인 예약의 **지금 종료**도 수동 변경 여부를 확인한 뒤 복귀합니다. 예약자가 사용 중지되거나 가격 수정 권한을 잃으면 시작 시 자동 공개를 중지합니다.

## 4. 신규 모델과 판매 상태

**모델·판매 상태 → 신규 모델 등록**에서 모델명·제조사·모델코드·용량·사진·색상을 입력합니다. 용량이 다른 상품은 각각 등록합니다. 기존 모델의 ID와 기존 용량 연결은 가격표에 사용되므로 변경하지 않습니다.

등록하면 가격표에 모델과 통신사·가입 조건 행이 생깁니다. **가격이 자동으로 채워지는 것은 아닙니다.** 필요한 출고가·지원금·요금제·구매 조건을 가격표에서 입력하고 공개하세요. 미등록 금액은 고객에게 확인 필요로 표시됩니다.

모델과 색상별로 **판매 중 / 품절 / 입고 예정 / 판매 종료**를 선택합니다. 품절·입고 예정·판매 종료는 고객에게 상태를 표시하고 문의할 수 있게 합니다. 품절·판매 종료 색상은 견적의 색상 선택에서 비활성화됩니다.

**고객 페이지에서 숨기기**는 상태 표시와 별도입니다. 숨긴 모델·용량은 고객 목록과 모델 선택에서 제외되며, 관리자 가격표와 과거 기록은 남습니다.

모델에서 색상 목록을 저장하면 가격표의 선택 색상도 함께 갱신됩니다. 목록에서 제거한 색상의 사진 연결은 현재 가격표에서 정리되며, 사진 파일과 이전 저장본은 보존됩니다. 가격표에 작성 중인 변경이 있으면 최신 가격을 불러와 입력을 유지하고 비교하라는 안내가 나옵니다. 색상 사진을 따로 바꾸려면 가격표의 **색상·사진**에서 편집하고 공개하세요.

## 5. 직원별 권한과 계정 사용 중지

대표 관리자는 **관리자 계정**에서 직원을 추가하고 업무 권한을 정합니다. **가격 담당 / 페이지 담당 / 조회 전용 / 전체 관리**를 선택한 뒤 세부 권한을 조정할 수 있습니다.

| 권한 | 허용하는 업무 |
| --- | --- |
| 가격표 수정 | 셀 수정·엑셀 반영·예약 공개 |
| 메인페이지 수정 | 문구·링크·영상·사진 선택과 공개 |
| 모델 등록·판매 상태 | 신규 모델·모델/색상 상태·숨김 |
| 사진 보관함 수정 | 업로드·이름 변경·미사용 사진 삭제 |
| 관심 통계 조회 | 고객 관심 통계 메뉴 열람 |
| 수정 기록 조회 | 직원별 변경 기록 열람 |

기본 가격표·메인 내용·모델·사진은 로그인한 직원이 열람할 수 있습니다. 수정 권한과 통계·기록 조회 권한은 따로 부여합니다. 사진 업로드 권한이 없어도 기존 보관함 사진을 선택해 자신의 편집 권한 범위에서 사용할 수 있습니다.

퇴사하거나 접근이 필요 없는 직원은 **계정 사용 허용**을 해제합니다. 권한·사용 상태 변경은 기존 로그인에도 반영되며 계정 사용 중지는 새 로그인도 막습니다. 수정 기록은 보존됩니다. 대표 관리자 계정은 전체 권한을 유지하며 사용 중지할 수 없습니다.

## 6. 사진 보관함

사진 이름·원본 파일명으로 검색하고 **모든 사진 / 업로드한 사진 / 페이지 원본 사진**을 구분해 볼 수 있습니다. 메인 페이지·모델·가격표 색상 사진의 **보관함에서 선택** 버튼도 같은 사진을 사용합니다.

**이 사진 사용**은 편집할 항목에 사진 주소를 넣습니다. 메인·가격표는 공개 확인까지 마쳐야 고객에게 반영됩니다. 이름 변경은 보관함에서 찾기 위한 이름을 바꾸며 사진 URL은 유지됩니다.

**사용 위치**에서 메인 페이지 구역·항목과 가격표·모델·이전 저장본·임시 작업·예약의 사용 여부를 확인할 수 있습니다. 이전 저장본에 사용한 사진도 복원을 위해 삭제할 수 없습니다. 배포에 포함된 원본 사진은 보관함에서 삭제하지 않습니다.

업로드 사진은 사용하지 않아도 자동 삭제되지 않습니다. **사용 위치 없음**인 업로드 사진만 확인 후 삭제할 수 있습니다. 저장 공간이 부족하다는 안내가 나오면 미사용 사진을 정리하거나 저장 공간을 늘려야 합니다.

## 7. 고객 관심 통계

**고객 관심 통계**에서 최근 7·30·90일을 선택합니다. 한국 날짜 기준으로 오늘을 포함하며 다음 수치를 보여줍니다.

- 모델 견적 조회 횟수
- 전화 버튼 클릭 횟수
- 카카오톡 링크 클릭 횟수
- 모델별 합계와 날짜별 추이

**클릭 횟수는 실제 상담 건수나 고유 방문자 수가 아닙니다.** 전화 연결·카카오톡 메시지 전송 여부는 수집하지 않습니다. 모델을 선택하지 않고 누른 상담 버튼은 별도 항목에 집계합니다.

관리자 미리보기와 관리자 로그인 상태의 클릭은 제외합니다. 같은 탭에서 30초 안에 반복한 동일 이벤트는 한 번으로 집계합니다. 브라우저·네트워크 상태와 요청 제한으로 일부 이벤트가 집계되지 않을 수 있습니다.

관심 통계 DB에는 고객 이름·전화번호·IP·브라우저 정보나 방문자 식별자를 저장하지 않습니다. Redis는 과도한 요청을 막기 위한 짧은 수명 카운터를 공유합니다.

## 개발·운영 인수인계

데이터는 MySQL 또는 MariaDB에 저장합니다. 가격·메인 내용·계정별 임시 작업·예약의 JSON은 관계형 DB의 JSON 문자열 컬럼에 보관하며, 모델·사진 메타데이터·계정·감사 기록·날짜별 통계는 별도 테이블로 관리합니다. 사진의 실제 파일은 `MEDIA_PATH`에 있고 DB는 사진 URL과 이름·용량·사용 정보를 참조합니다. **DB와 사진 파일을 함께 백업·복구해야 합니다.**

여러 서버로 배포할 때는 모든 인스턴스가 같은 DB·Redis와 같은 사진 파일 저장소를 사용해야 합니다. 예약은 DB 행 잠금으로 중복 적용을 방지하고, 사진 참조 저장과 삭제도 DB 메타데이터 잠금으로 조정합니다. JWT 유효성뿐 아니라 계정 상태·권한과 Redis 토큰 등록을 요청마다 확인합니다.
