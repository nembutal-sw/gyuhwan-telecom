## 보안 수정 확인 — 2026-10-10

- Spring Boot 4.1.1로 올리고 JSON 변환은 기존 Jackson 2 자료형과의 호환 설정을 사용합니다. 전체 백엔드 자동 검사 61개가 통과했습니다.
- 로그인은 CSRF 검사 후 Redis의 원자적 카운터로 접속 주소·계정별 10분 20회까지, 사진 업로드는 관리자별 1시간 30회까지 허용합니다. 한도 초과는 429, Redis 장애는 503으로 처리합니다. 여러 서버 인스턴스가 같은 Redis를 사용합니다.
- PNG·JPEG는 새로 인코딩하고 WebP는 메타데이터 청크를 제거합니다. 이미지 처리 동시성·크기와 저장 공간 기본 256MiB를 제한합니다. 7일 지난 미사용 이미지를 정리하되 현재·이전 버전에서 참조하는 이미지는 보존하는 검사가 통과했습니다.
- 영상 iframe은 서버 저장 검증과 고객 화면·관리자 미리보기에서 HTTPS YouTube·Vimeo만 허용합니다. CSP의 frame-src도 두 영상 도메인으로 한정했습니다. 공개 가격표는 인스턴스마다 2초 캐시하며 저장 후 해당 인스턴스의 캐시를 지웁니다.
- Docker 빌드에서 `.runtime`을 제외했습니다. Swarm 예시의 앱 8080 공개 포트를 제거하고 Cloudflare Tunnel 또는 TLS 원본 프록시 연결 방법을 [배포 안내](../deploy/DEPLOYMENT.md)에 정리했습니다. 실제 Cloudflare 연결은 아직 구성하지 않았습니다.
- 최신 JAR를 로컬 127.0.0.1:8080 서버에 적용했습니다. 실제 MySQL·Redis 준비 상태 `UP`, `admin/admin` 로그인 204와 관리자 조회, 가격·메인 내용 버전 4 유지를 확인했습니다. 로컬 HTTP용 `COOKIE_SECURE=false`는 공개 HTTPS 배포에 사용하지 않습니다.

## 배포 예시와 검증 범위

- MySQL Compose, MariaDB override, Kubernetes, Swarm YAML 문법 검사 성공. 비밀 값 생성기·미리보기 JS 문법 검사 성공.
- 같은 DB·Redis·JWT 키를 사용하는 실제 앱 두 개의 로그인 공유와 로그아웃 무효화를 확인했습니다. 사진 공유는 배포 예시에 RWX/NFS 구성을 포함했습니다.
- Docker·Kubernetes·Swarm은 이 PC에 설치되어 있지 않아 실제 이미지 빌드나 클러스터 배포는 수행하지 않았습니다.
- 운영 DB·HTTPS 도메인 연결, 실제 휴대폰 기기, 운영 저장소 장애·백업 복구는 별도 운영 환경에서 확인해야 합니다. 현재 모바일 검사는 앱 브라우저의 미리보기입니다.
- 기존 chatgpt.site 공개 호스팅에는 변경을 배포하지 않았습니다. 현재 변경은 로컬 서버와 새 배포 파일에 적용되어 있습니다.
