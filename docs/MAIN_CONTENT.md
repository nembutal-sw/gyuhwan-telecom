# 메인 페이지 직접 편집

고객 메인 화면은 `/`, 관리자 로그인은 `/admin_login`, 관리자 화면은 `/admin`입니다.

관리자 메뉴의 **메인 페이지 관리**를 열면 고객에게 보이는 실제 페이지가 먼저 나타납니다. 상단 메뉴, 배너, 영상, 휴대폰 카드, 인터넷·TV, 상담 안내, 매장 정보, 지도, FAQ, 부가서비스, QR, 하단과 구매 안내창을 화면에서 찾아 수정합니다.

## 수정 순서

1. **직접 편집** 상태에서 바꾸려는 문구·사진을 더블클릭합니다. 메뉴·연결 링크·이동 버튼은 한 번 클릭하면 페이지로 이동하지 않고 해당 부분의 편집창이 열립니다. 사진·영상의 **사진 수정**·**영상 수정** 버튼을 눌러도 됩니다. 모바일에서는 문구를 터치하거나 수정 버튼을 누릅니다.
2. 열린 **선택한 부분 수정** 창에서 문구·사진·사진 설명·영상 주소·연결 주소 등을 바꿉니다. 입력한 모습은 페이지에 바로 보이지만 아직 고객 페이지에는 저장되지 않습니다.
3. **편집 마치기** 또는 **닫기**를 누르고 다른 부분을 수정합니다. 창을 닫거나 **구역 이동**으로 다른 구역을 보아도 입력값이 유지됩니다. 상단에 `저장 전 변경 N개 · N개 구역`이 표시됩니다.
4. **미리보기**로 전환해 수정한 페이지를 확인합니다. 이 상태에서는 메뉴·링크를 고객 화면처럼 사용할 수 있습니다. **PC**·**모바일**로 화면 폭을 바꾸고, **실제 크기**·**화면에 맞춤**으로 표시 크기를 선택할 수 있습니다.
5. **변경 내용 저장**을 누르면 여러 구역의 변경 전후 값이 한 창에 모입니다. 내용을 확인한 뒤 **고객 페이지에 저장**을 누릅니다. 더 고칠 부분이 있으면 **계속 수정**을 누릅니다.

저장 후 **고객 메인페이지 열기 ↗**로 공개 화면을 확인합니다. 이 링크는 현재 저장된 고객 페이지를 엽니다. 관리 화면의 저장 전 입력값은 공개 화면에 표시되지 않습니다.

키보드로는 페이지의 수정 대상을 Tab으로 선택한 뒤 F2를 눌러 편집할 수 있습니다. 일반 문구는 Enter로도 열 수 있습니다. 편집창에서 Esc를 누르면 입력값을 유지하며 닫습니다.

## 화면에서 찾기 어려운 항목

**구역 이동**에서 원하는 구역을 고른 뒤 **이 구역의 모든 항목**을 누릅니다. **편집할 항목 그룹**으로 모델 정보·사진, 구매 안내, 인터넷 상품·월 요금, 설치 안내, 부가서비스 상품 등을 선택하고 **항목 찾기**로 문구나 사진 설명을 검색합니다.

화면에서 직접 선택하기 어려운 숨겨진 항목이나 제품 용량별 정보도 이 목록에서 수정할 수 있습니다. 추천 버튼의 **연결할 모델**은 해당 버튼이 여는 견적 대상을 바꿉니다. 같은 제품·상품 데이터를 사용하는 여러 위치에는 변경한 정보가 함께 표시됩니다.

원본 HTML 구조와 CSS의 글씨체·글자 크기를 유지합니다. 관리자에 스타일 변경 설정은 없습니다. 문구는 HTML로 실행하지 않습니다. 가격 견적과 색상별 사진은 가격 관리 화면에서 별도로 저장하고 공개 화면이 현재 저장값을 읽습니다.

## 사진과 영상

사진 수정 창에서 사진 주소를 바꾸거나 **새 사진 올리기 · PNG·JPG·WebP**로 파일을 선택합니다. 25MB 이하 원본을 받을 수 있고, 큰 사진은 브라우저에서 최대 2,000px, 1.5MB 이하로 줄입니다. 실제 사진 파일은 `MEDIA_PATH`(기본 `./data/media`)에 저장하며 `/media/<생성된 파일명>`으로 제공합니다. 업로드 후 **변경 내용 저장 → 고객 페이지에 저장**까지 마쳐야 고객 화면의 사진이 바뀝니다. 기본 원본 사진·색상칩과 Noto Sans KR 폰트 파일은 실행 파일에 포함됩니다.

영상 수정 창에는 HTTPS YouTube 일반·짧은·embed 주소 또는 Vimeo 주소를 입력합니다. 공개 화면은 이 두 서비스의 주소만 영상 플레이어로 바꿔 표시하며, 영상 편집창에도 같은 플레이어가 나타납니다. 외부 영상·사진은 외부 서비스에 연결할 수 있어야 표시됩니다. 동영상 파일 자체의 업로드와 임의 웹페이지·동영상 파일 주소 삽입은 제공하지 않습니다.

## 저장된 내용과 저장 시각

화면 상단에는 **고객페이지에 적용된 저장본**, **마지막 저장**, **이 화면에서 확인한 시각**이 표시됩니다. 마지막 저장은 이 서버에 메인페이지 내용을 저장한 시각이고, 확인 시각은 관리자 화면이 그 내용을 가져온 시각입니다. 수정 중에는 **저장하지 않은 변경이 있습니다**로 표시합니다. 가격표와 메인페이지 내용은 따로 저장하므로 각 화면의 마지막 저장 시각이 다를 수 있습니다.

여러 구역에서 바뀐 항목을 한 번에 저장합니다. 다른 관리자나 다른 창이 먼저 저장했으면 충돌을 표시하고 현재 입력값을 유지합니다. **최신 내용 불러오기 · 입력 유지**를 누른 뒤 최신 저장값과 변경 내용을 다시 확인합니다.

**변경 취소**는 아직 저장하지 않은 모든 구역의 입력을 취소합니다. **고객페이지에 적용된 내용 다시 확인**은 이 서버에 저장된 메인페이지 내용을 다시 가져옵니다. 미저장 변경이 있으면 취소 여부를 확인하며, **다시 불러오기**를 누르면 입력이 취소됩니다. 미저장 입력은 현재 열린 관리 화면에 보관되므로, 작업을 마칠 때는 저장을 완료하세요.

하단 **이전 저장본으로 되돌리기**를 펼쳐 원하는 날짜·시각의 **이 저장본으로 되돌리기**를 누릅니다. 확인창에서 **이 저장본 적용하기**를 누르면 모든 구역의 내용·사진·연결 주소를 해당 저장본으로 되돌리고 저장 전 입력도 취소합니다. 사진 파일과 DB를 함께 백업해야 합니다. Docker Compose는 MySQL `database_mysql`(MariaDB override는 `database_mariadb`) 볼륨과 사진 `media` 볼륨을 각각 유지합니다.

현재 작업은 로컬 서버에 반영되며 기존 `chatgpt.site` 호스팅에는 자동 반영되지 않습니다.

가격 관리에도 **수정한 가격 메인페이지 미리보기**가 있습니다. 현재 선택한 모델·통신사·가입 유형·할인 방법의 견적창을 수정 중인 가격으로 표시하며 저장 전 미리보기는 DB 값을 바꾸지 않습니다.
